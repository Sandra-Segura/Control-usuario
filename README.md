# Control de usuarios

Gestión integral y automatizada de identidades y accesos (IAM): ciclo Joiners, Movers y Leavers.

## Contenido

- `historias/historias_de_usuario.md`: 24 historias de usuario en 9 épicas, con criterios de aceptación, prioridad MoSCoW, puntos y sprint.
- `historias/historias_jira.csv`: las mismas historias en formato CSV para importar a Jira.

Plan del piloto (PoC): 4 sprints de 2 semanas. Los puntos son una estimación inicial a validar con planning poker.
